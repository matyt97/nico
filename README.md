# Fisiopatología II · Digestivo

Plataforma de estudio (tarjetas con repetición espaciada, quiz, casos clínicos, flujos, repaso) basada en el PDF de clases.

Es una sola página estática: no necesita instalación ni servidor.

## Publicar con GitHub Pages
1. Sube `index.html` y este `README.md` a la raíz del repositorio.
2. Settings > Pages > Source: Deploy from a branch > Branch: `main` / carpeta `/ (root)` > Save.
3. En un par de minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

El avance se guarda en el navegador de cada dispositivo (localStorage).
